## 流量型和流量不限型，差的到底是什么

这个规则不搞明白，很容易在月末被限速。

看到套餐里写着 "XXX GB" 流量，就是**流量型**：上行下行一起算，每月用不完的流量可以叠加到次月，用完之后带宽被压到很低——多数区域限到 5Mbps，日本一区和韩国的部分机型压到 1Mbps。想恢复高速就得买流量包，价格按区域单独定，比如香港五区约 20元/TB，香港二区约 200元/TB，差价十倍，买之前看清楚。

没写流量的就是**不限流量型**：带宽标称值通常低一些，但随便跑。举例来说，同配置的温州 4核8G 机型，不限流量版上行只有 25Mbps，但月付比大带宽版便宜 20 元。

一句话选：跑长期稳定业务选不限流量，需要短时间大口径传输（下载站、镜像、视频中转）就选流量型配流量包。

## 几个容易踩的坑

**NAT 机型不等于没有公网。** 国内很多游戏云和部分云服务器默认是 NAT，和别人共用一个公网 IP，靠端口映射对外提供服务。端口数量有限（一般 10~15 个），要独立 IP 得另外买。国内高防区域的独立 IP 会明显贵一些，买之前先确认自己的业务能不能接受端口映射。

**系统盘备份默认开着，费用不可关闭。** 0.1元/GB/月，30G 的系统盘就是每月 3 元。这不是坑，但算总价时别漏掉。

**扩容按介质计价，差价很大。** SSD 云盘和高速 NVMe 是 0.4元/GB/月，高效云盘只要 0.1元/GB/月。数据库类应用老老实实上 SSD，纯存附件和数据备份用高效云盘就行，上限也不同（高效云盘最高可到 1000G）。

**部分区域会缺货。** 香港二区就经常处于无货状态，看中的机型没库存，换三区或五区通常是可行的替代。
